Hermes Agent — Personal Calendar Recap

A personal assistant operated by Rémi Arnould that prepares upcoming calendar summaries and delivers them to the account owner via Telegram.

How it works

With the owner's permission, the assistant reads Google Calendar events and may read Gmail messages for event context. It can also read iCloud calendar events. The assistant uses that information to prepare an agenda, including event times, locations, links and potential conflicts.

Google access is read-only: the recap does not send or modify email or create, change or delete calendar events.

This is a personal integration, not a public sign-up service. Contact: remi.arnould2@gmail.com.
